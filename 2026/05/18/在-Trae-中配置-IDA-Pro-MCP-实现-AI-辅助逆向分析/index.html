常见问题

问题 解决方法
No IDA instances discovered 确保 IDA Pro 已打开并加载了二进制文件
Python 配置警告 使用 idapyswitch --force-path 重新指定 Python DLL 路径
端口被占用 插件会自动尝试其他端口，查看 IDA 输出窗口确认实际端口

两种工作模式对比

模式 优点 适用场景
GUI 模式（HTTP） 配置简单，立即使用 日常逆向分析、CTF 比赛
无头模式（idalib） 无需打开 IDA 界面 服务器批量自动化分析

本文介绍的是 GUI 模式，配置更简单，适合大多数使用场景。
